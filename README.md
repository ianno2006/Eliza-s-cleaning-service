## 🚀 How to Publish on GitHub Pages (Step-by-Step)

Hosting this website is completely free using **GitHub Pages**:

### Option 1: Using GitHub Web Interface (Easiest)
1. Go to [GitHub.com](https://github.com) and sign in.
2. Click the **+** (plus icon) in the top right and select **New repository**.
3. Name your repository (for example: `elizas-cleaning-service`).
4. Keep it **Public**, leave "Initialize with a README" unchecked, and click **Create repository**.
5. On the empty repository page, click **uploading an existing file**.
6. Drag and drop `index.html`, `styles.css`, and `README.md` into GitHub.
7. Click **Commit changes**.
8. In your repository, click **Settings** (top menu bar).
9. In the left sidebar, click **Pages**.
10. Under **Build and deployment > Branch**, choose `main` (or `master`) and folder `/ (root)`, then click **Save**.
11. Wait 1–2 minutes. GitHub will display your live website URL (e.g., `https://<your-username>.github.io/elizas-cleaning-service/`).

### Option 2: Using Git via Terminal / Command Prompt
```bash
git init
git add .
git commit -m "Initial commit for Eliza's Cleaning Service website"
git branch -M main
git remote add origin https://github.com/<your-username>/elizas-cleaning-service.git
git push -u origin main
```
Then go to **Settings > Pages** on GitHub and enable GitHub Pages on the `main` branch.
